## Phase 3: User Story 1 - Retry a failed run, run from a node, run up to a node (Priority: P1) 🎯 MVP

**Ticket**: `.scratch/n8n-parity/issues/11-retry-run-from-to.md` · **Depends on**: Foundational (01)

**Goal**: A late failure no longer costs every earlier agent node: retry from the failed step, run from any node reusing upstream outputs, or run only up to a node; from the run page or `ctc retry`.

**Independent Test**: Engine seam: a 5-node chain fails at node 4; retry executes only node 4 onward, nodes 1-3 are `reused` with the parent's outputs, the worktree starts at node 4's pre-commit; run-to stops `done` after the chosen node; a pruned parent is rejected.
