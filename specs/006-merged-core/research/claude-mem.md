## Architecture

Local worker mode is the default (hooks, worker daemon, SQLite, Chroma). Server mode (`CLAUDE_MEM_RUNTIME=server`) swaps in Postgres/BullMQ and is selected per hook ([runtime-selector ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/services/hooks/runtime-selector.ts)); hooks fall back to the local spool if the server is unreachable ([observation L120-140 ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/cli/handlers/observation.ts#L120-L140)).

boxes:
- `Claude Code` | host | emits hook events, reads injected context
- `hooks.json` | plugin | maps 9 events to `claude-mem hook claude-code <name>` ([hooks ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/plugin/hooks/hooks.json))
- `claude-mem launcher/CLI` | cli | short-lived process; normalizes stdin, applies skip rules, writes spool file or calls worker (`src/cli/handlers/*`)
- `Hook spool dir` | storage | one JSON file per event under `~/.claude-mem/state/hook-spool` ([hook-spool L214 ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/shared/hook-spool.ts#L214))
- `Worker daemon (Express :37700+uid%100)` | worker | routes, session manager, providers, search, SSE ([worker-service L278 ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/services/worker-service.ts#L278))
- `SessionManager + SessionMessageBuffer` | worker | per-session in-RAM queue and observer conversation ([SessionMessageBuffer ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/services/worker/SessionMessageBuffer.ts))
- `ClaudeProvider (observer)` | llm | one streaming `query()` per Claude Code session, tools locked down ([ClaudeProvider L501 ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/services/worker/ClaudeProvider.ts#L501), [hardened-options ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/sdk/hardened-options.ts))
- `parser + ResponseProcessor` | worker | XML parse, reject/retry, store, sync (`parser.ts:94`, [ResponseProcessor L521 ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/services/worker/agents/ResponseProcessor.ts#L521))
- `SQLite (SessionStore)` | storage | observations, session_summaries, user_prompts, sdk_sessions, tool_uses, work_state_entries, FTS5
- `ChromaSync + chroma-mcp (uvx)` | storage | per-project collection `cm__<project>` ([ChromaSync L391 ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/services/sync/ChromaSync.ts#L391))
- `SearchOrchestrator` | worker | Chroma-first, SQLite fallback/backfill ([SearchOrchestrator L107 ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/services/worker/search/SearchOrchestrator.ts#L107))
- `ContextBuilder` | worker | renders SessionStart block within 10,000 chars ([ContextBuilder L109,372 ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/services/context/ContextBuilder.ts#L109), [ContextBudget L9 ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/services/context/ContextBudget.ts#L9))
- `MCP server (stdio)` | mcp | 26 tools, progressive disclosure (`mcp-server.ts:518+`)
- `Viewer UI + SSE` | ui | React SPA at worker root, `/stream` ([ViewerRoutes L222 ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/services/worker/http/routes/ViewerRoutes.ts#L222))
- `Server runtime (optional)` | server | `/v1/*` REST, API keys, BullMQ lanes, Postgres+pgvector (`server/*`)
- `Cloud sync hub (optional)` | cloud | push drain keyed by `synced_at IS NULL` ([CloudSync ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/services/sync/CloudSync.ts)) [not read beyond header]

arrows:
1. Claude Code → hooks.json → CLI: event + stdin JSON (hot, synchronous start, `PostToolUse` is `async:true`)
2. CLI → Hook spool dir: write one atomic file per event, exit without waiting (hot; observation, file_edit, summarize, session_end, subagent_stop, advisor_calls, deliverables, work_state_telemetry)
3. CLI → Worker: short "nudge" request to the worker (250 ms timeout, endpoint path not read) so it drains now (hot, best-effort; [spool-hook-event L13 ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/cli/spool-hook-event.ts#L13))
4. CLI(UserPromptSubmit) → Worker: `POST /api/sessions/init` (hot, 10 s budget, optional `/api/context/semantic`)
5. CLI(SessionStart) → Worker: `GET /api/context/inject` (hot, 60 s hook timeout, 10,000-char output cap)
6. Hook spool dir → Worker: drain on boot, nudge, `fs.watch`, 30 s safety sweep (cold; [hook-spool-drain L8 ↗](https://github.com/thedotmack/claude-mem/blob/325afb60108d4ab04e24d715f244bd591ca33fbe/src/services/worker/hook-spool-drain.ts#L8))
7. Worker → SessionMessageBuffer: ingest filters (skip tools, project exclusion, bash patterns, private tags) then enqueue deduped by `tool_use_id` (cold)
8. SessionMessageBuffer → ClaudeProvider: generator yields claimed batch (batch size default 1) as observation prompt (cold)
9. ClaudeProvider → parser: observer reply text; reject classes: overflow, quota, auth, transport, non-XML (cold)
10. parser → SQLite: one transaction `storeObservations` (hash dedup, optional Tier-0 merge, reinforcement) (cold)
11. SQLite → ChromaSync: `syncObservation` fire-and-forget, 100-doc batches (cold)
12. Stop hook → spool → Worker → ClaudeProvider: summary prompt in the same observer conversation → `session_summaries` row (cold)
13. SessionStart → ContextBuilder → SQLite: newest N observations + summaries, fit-by-measuring (hot read)
14. MCP client → MCP server → Worker `/api/search|timeline|observations`: index → timeline → details (hot read)
15. Worker → Viewer: SSE events for new observations and processing status (cold)
16. (server mode) CLI → `/v1/events` → Postgres `agent_events` + `observation_generation_jobs` → BullMQ → generation worker → `observations` + `observation_embeddings` (cold)
