# graphify — reverse-engineered architecture spec (for the ctc "context graph" rebuild)

- Repo: https://github.com/Graphify-Labs/graphify (PyPI `graphifyy`, Apache-2.0). Docs: graphify.com.
- Read: installed `graphifyy` **0.9.93** (`.../site-packages/graphify/`, 87,625 py lines) + shallow clone SHA `0a8cd4e1e342235fe53e881fb5d591bf0460071f` (pyproject says 0.9.97, 2026-10-27) for ARCHITECTURE.md / BENCHMARKS.md / README skim. Real output `claudethecaller/graphify-out/` and read-only `graphify query|explain|path|affected|god-nodes` runs. Date 2026-10-30.
- Code line numbers below are from the **installed 0.9.93** files. The clone is 4 patch versions newer: [UNVERIFIED] that behaviour is identical.
- Read in depth: build, extract (dispatch + cross-file passes), cluster, dedup (structure), cache, detect (structure), watch (`_rebuild_code`), serve (scoring/BFS/path/MCP), affected, hooks/cli hook-guard, install (Claude), markdown extractor, mcp_ingest/manifest_ingest (headers), llm (backend table), export.to_json, analyze (god/surprise).

## Architecture

boxes:
- `detect` (build) — walk tree, classify code/doc/paper/image/video, honour .gitignore/.graphifyignore, secret-file skip, manifest diff. [detect L1957 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/detect.py#L1957)
- `extract` (build) — per-file tree-sitter/regex extractors in a process pool, plus cross-file resolution passes. [extract L9171 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/extract.py#L9171)
- `semantic` (build, optional LLM) — docs/papers/images → nodes/edges via subagents or `graphify extract --backend`. [skill ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/skill.md), [llm ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/llm.py)
- `validate` (build) — extraction schema check before build. [validate ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/validate.py)
- `build+dedup` (build) — merge extractions, normalise ids, entity dedup, `nx.Graph`. [build L1863 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/build.py#L1863), [dedup L950 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/dedup.py#L950)
- `cluster` (build) — Leiden/Louvain, split oversize, cohesion score, hub-named labels. [cluster L233 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/cluster.py#L233)
- `analyze` (build) — god nodes, surprising connections, questions, cycles, graph_diff. [analyze ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/analyze.py)
- `report+export` (build) — graph.json (+ shrink guard), GRAPH_REPORT.md, html, other formats. [export L287 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/export.py#L287), [report ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/report.py)
- `cache+manifest` (store) — per-file hash cache, manifest of last-seen hashes. [cache ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/cache.py), [detect L2595 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/detect.py#L2595)
- `graph.json` (store) — the only artifact the query side reads. [`graphify-out/graph.json`](../../../graphify-out/graph.json)
- `watch/update` (build) — incremental AST-only rebuild with lock and pending queue. [watch L1677 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/watch.py#L1677)
- `git hooks` (trigger) — post-commit/checkout/merge/rewrite run the rebuild detached. [hooks L1093 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/hooks.py#L1093)
- `query engine` (query) — lexical seed scoring, BFS/DFS with hub cut-off, token-budget text render. [serve L575-1311 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/serve.py#L575-L1311)
- `path / affected` (query) — directed shortest path; reverse BFS over relation set. [serve L2027 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/serve.py#L2027), [affected L244 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/affected.py#L244)
- `CLI` (query) — `query explain path affected god-nodes`, exit codes 0/3/4. [cli L1531-2077 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/cli.py#L1531-L2077)
- `MCP server` (query) — 10 tools + 6 resources over the same functions; hot-reloads graph.json. [serve L2189 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/serve.py#L2189)
- `hook-guard` (query, Claude Code) — PreToolUse nudge with up to 5 matching nodes. [cli L1089 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/cli.py#L1089)
- `skill + CLAUDE.md block` (agent glue) — tells the agent to run `graphify query` before grep/read. [skill ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/skill.md), [claude-md ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/always_on/claude-md.md)
- `global/merge` (multi-repo) — prefix per repo, union, cross-repo call pass. [global_graph ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/global_graph.py), [cross_repo_calls ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/cross_repo_calls.py), [build L2778 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/build.py#L2778)

arrows:
1. detect → extract — code file list (+ doc list to semantic) — build-time
2. extract → cache+manifest — read/write per-file result by content hash — build-time
3. semantic → build+dedup — LLM fragment JSON, `_origin` stamped — build-time
4. extract → build+dedup — AST nodes/edges with `_origin="ast"` ([extract L10987 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/extract.py#L10987)) — build-time
5. build+dedup → cluster — `nx.Graph` — build-time
6. cluster → analyze — communities + cohesion — build-time
7. analyze → report+export — gods, surprises, questions — build-time
8. report+export → graph.json — node_link JSON, sorted, schema_version 1 — build-time
9. git hooks → watch/update — detached rebuild on commit — build-time
10. watch/update → extract — changed files + `resolution_context_nodes` from old graph ([watch L1985-2135 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/watch.py#L1985-L2135)) — build-time
11. graph.json → query engine — `_read_graph` + `_GraphContextCache` — query-time
12. query engine → CLI / MCP server — rendered text subgraph — query-time
13. CLI → hook-guard — `last_query_stamp` file suppresses nudges for 1800 s ([cli L904-927 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/cli.py#L904-L927)) — query-time
14. hook-guard → Claude Code — `hookSpecificOutput.additionalContext` on PreToolUse — query-time
15. skill+CLAUDE.md → agent — rule "run `graphify query` before grep/read" — query-time
16. graph.json (many) → global/merge — `~/.graphify/global-graph.json` — build-time

## Graph schema

Output: [`graphify-out/graph.json`](../../../graphify-out/graph.json) = networkx `node_link_data(edges="links")`. Top keys: `directed` (false), `multigraph` (false), `graph` {`schema_version`:1, `graphify_version`}, `nodes`, `links`, `hyperedges`, `built_at_commit`. Arc order is the direction ([ARCHITECTURE ↗](https://github.com/Graphify-Labs/graphify/blob/0a8cd4e1e342235fe53e881fb5d591bf0460071f/ARCHITECTURE.md); [serve L1978-2024 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/serve.py#L1978-L2024)).
This repo: **2,863 nodes, 6,914 links, 173 communities** (151 shown), 2.7 MB; cache 11 MB. 89% EXTRACTED / 11% INFERRED / 0 AMBIGUOUS; token cost 0.

**Node id**: `ids.make_id` = casefold+NFKC fixpoint, runs of non-word chars to `_`. Code: `{full path sans ext}_{entity}` (e.g. `src_ctc_decision_bundle_suggestion_line`). Same id from AST, LLM and builder ([ids L1-60 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/ids.py#L1-L60)).
**Node attrs** (union seen): `id label norm_label file_type source_file source_location community community_name _origin` plus optional `node_kind` (`page|heading`), `_callable`, `_callable_class`, `frontmatter`, `metadata`, `type`(`external|package`), `ecosystem`, `version`, `external`, `_py_fixture`, `_py_property`.
**file_type** (closed enum; others rewritten to `concept`, [build L351 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/build.py#L351)): `code 1549 | document 818 | rationale 395 | concept 101` (also `paper`, `image`).
**Node kinds in practice**: file node (label = basename), class, function/method (`name()`), markdown `page` and `heading`, `rationale` (docstring/comment text), external stub (imports like `asyncio`), package, MCP `mcp_server|mcp_command|mcp_package|env_var` ([mcp_ingest ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/mcp_ingest.py) header).
**Edge relations (this graph)**: `calls 2035, contains 1854, references 841, imports 831, imports_from 487, rationale_for 395, uses 138, indirect_call 128, method 109, inherits 68, defines 28`. Other relations in code: `extends implements mixes_in embeds re_exports dynamic_import requires depends_on requires_env semantically_similar_to`.
**Edge attrs**: `source target relation confidence(EXTRACTED|INFERRED|AMBIGUOUS) confidence_score weight source_file source_location _origin context(call|import|parameter_type|argument|decorator|return_type|submodule_import) type_only`.
**Confidence rule**: EXTRACTED = 1.0; INFERRED score from a fixed set {0.95,0.85,0.75,0.65,0.55}; AMBIGUOUS 0.1-0.3 (`extraction-spec.md`). Member call via inferred receiver type = INFERRED 0.85 ([extract L4706 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/extract.py#L4706)).
**Tier provenance** `_origin`: `ast` vs semantic; incremental rebuild replaces only the same tier ([build L45-66 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/build.py#L45-L66), [extract L10987 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/extract.py#L10987)). In this graph every link is `ast`.

**5 Caching**: stat fast-path index (`size+mtime_ns`, 2 s mtime granularity guard) → content hash → per-file extraction JSON; MCP `_GraphContextCache` (max contexts env-configurable) hot-reloads on graph.json mtime; trigram index and path-search DiGraph cached on `G.graph`; module-level resolver caches cleared per `extract()` run ([extract L9217-9245 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/extract.py#L9217-L9245), approx.).

**6 Failure modes**: all hooks fail open and exit 0; `_safe_extract` returns empty result on parser error and the file stays unstamped so it retries; truncated LLM output marked hollow/partial; JSON repair of model output ([llm L1079-1240 ↗](https://github.com/Graphify-Labs/graphify/blob/b90b9df7949bd04a15b40a1624af85d0a9cfdf04/graphify/llm.py#L1079-L1240)); ambiguous names refuse instead of guessing; known weak spot: lexical query on a natural-language prompt returned 559 nodes (79 shown) with hubs like `asyncio`, `numpy`, `cfg()` (observed: `graphify query "per prompt hook suggestion graph line"`); `god-nodes` top = `cfg()` 115 edges.
