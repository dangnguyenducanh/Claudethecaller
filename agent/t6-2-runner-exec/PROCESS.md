# Process for T6.2: runner cold path (worktree recipe, setup hook, agent registry, stream, report token, restart sweep) (TypeScript)

Every step ends with a check; the next step does not start before it passes. Language and file names adapted from the standard process: Python → TypeScript strict on Node 22, `pytest` → Vitest, `tests/test_*.py` → `*.test.ts` next to the code, `NotImplementedError` → `throw new Error('not implemented')`, docstring → TSDoc comment, `monkeypatch` → pass fakes through `deps` (`repos`, `config`, `runsDir`, `reportBase`, `resolveNode`, `onStepEnd`, `log`) and assign to the exported `runnerExecLimits` object, restoring it in `afterEach`. Modules: `packages/core/src/runner/` (pure) and `apps/worker/src/runner/` (all I/O: git, processes, files, `repos`).

1. Read the callers and rules. Grep every call site. Done when you can say, per call site, what goes in, what is done with the result, and what the module must never do. Also run the real upstream producer on a sample and keep the output as a fixture.
   (Here: the call sites are `runAttempt` and the `Handler` type in `apps/worker/src/jobs/consumers.ts`, the `runner.step` payload and `timeoutMs('runner', ...)` in `packages/shared/src/queues/`, `JobDropped` in `queues/submit.ts`, `repos.runner.*` and `repos.system.runner.listRunningSteps` with `createSystemCtx` in `packages/shared/src/repositories/`, the `wf_steps` columns in `packages/shared/migrations/0005_runner.sql`, `runner.*` defaults in `packages/shared/src/env/schema.ts`, the T6.1 core in `packages/core/src/runner/index.ts` (`transitionStep`, `failStep`, `advanceStage`, `reportStep`, `runnerJobId`) and the report route in `apps/web/src/runs/index.ts`; the pattern for a worker module with `deps` is `apps/worker/src/memory/index.ts` and its `testing.ts` (scratch schema). The real upstream producers are two: `git` and the agent stream. Run `git worktree add --no-track -b <branch> <path> <base>` in a throwaway repo and keep the exact stderr of a second add of the same branch as a fixture (`apps/worker/src/runner/fixtures/git-branch-exists.txt`). For the stream you may not start `claude` or `codex`: write `apps/worker/src/runner/fixtures/claude-stream.jsonl` and `codex-stream.jsonl` by hand from the line shapes in DECISIONS.md D11 and `scripts/fake_claude_quota.sh` (read only), and say in the report that they are hand-written.)
2. Write header, constants, signatures only (bodies `throw new Error('not implemented')`). Header: what the module is, called from, why it exists, deliberately NOT done. Each constant gets the real reason, or `chosen by judgment`: never an invented reason. Each function gets a TSDoc comment: trust, return, copies or modifies, bad input. Done when it imports and the header answers who calls it, why, and what it does not do.
3. Write tests first, covering every decision id. One behaviour per test. For every limit: shrink by assigning to `runnerExecLimits` (restore it after), equal is valid, one more is an error (or is cut, where D2 says so), pin the default. Compare errors with `toEqual`/`toBe` on `message` and `code`. Must-NOT tests for every non-goal and every D6 item (no token anywhere, no forced git, no bypass flag, no status write outside the core, no kill of a quiet agent). Public names, throwaway repos and scratch schema names only. Write the three `runner.crash` gate tests with the exact names from SPEC.md. Done when the tests collect and fail.
4. Smallest code that passes. Reuse the repo's helpers (`repos.*`, the T6.1 core, `JobDropped`, `node:child_process`, `node:crypto`, `yaml`). Add nothing the decisions do not list. Silence rule D8. Done when tests, checks, lint and scope pass.
5. Run the self-check, fix every FAIL. Done at `SELFCHECK: DONE`.
6. Report in at most 150 words: commands and results, every `judgment:` call, doubts.
