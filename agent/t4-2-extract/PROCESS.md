# Process for T4.2 `packages/core/src/sanitize` + `packages/core/src/memory` + `packages/shared/src/models` + `apps/worker/src/memory` (TypeScript)

Every step ends with a check; the next step does not start before it passes. Language and file names adapted from the standard process: Python → TypeScript strict on Node 22, `pytest` → Vitest, `tests/test_*.py` → `*.test.ts` / `*.int.test.ts` next to the module, `NotImplementedError` → `throw new Error('not implemented')`, docstring → TSDoc comment, `monkeypatch` → assign to the exported `memoryLimits` / `modelLimits` object and restore it in `afterEach`. Module paths: `packages/core/src/sanitize/`, `packages/core/src/memory/`, `packages/shared/src/models/`, `apps/worker/src/memory/`.

1. Read the callers and rules. Grep every call site. Done when you can say, per call site, what goes in, what is done with the result, and what the module must never do. Also run the real upstream producer on a sample and keep the output as a fixture.
   (Here: the handlers' caller does not exist yet; the "call sites" are the APIs they must fit, named in DECISIONS.md D9: `Handler`, `runAttempt`, `startWorkers` in `apps/worker/src/jobs/`; `JobDropped` and the `llm.extract` / `llm.summarize` payloads in `packages/shared/src/queues/`; `repos.memory` (`nearest`, `add`, `reinforce`, `rewrite`, `supersede`, `insertSummary`, `getSummary`) and `repos.sessions.get` in `packages/shared/src/repositories/`; `memoryHash` in `packages/shared/src/memory-hash/`; `epoch.rotate` in `packages/shared/src/cache/`; `memory.bands`, `llm`, `embed_url`, `claude_home` in `packages/shared/src/env/schema.ts`; the producer `apps/web/src/spool/index.ts` (what it puts in the payloads). The real upstream producer of the transcript is Claude Code: you cannot run it and must not read `~/.claude`, so write two fixture transcripts by hand as `apps/worker/src/memory/fixtures/session-a.jsonl` (user facts, assistant text that quotes an instruction from a README, a tool_use + tool_result pair, a meta row, a sidechain row, a `<system-reminder>` and a `<private>` block inside a user turn, a slash command, a `[Request interrupted` row, one line that is not JSON, a trailing partial line) and `session-runner.jsonl` (rows with `cwd` under `/.ctc/wt/`). Keep the `userTurns`, `extractInput` and `sessionText` outputs of `session-a.jsonl` as `fixtures/session-a.expected.json` once step 4 produces them, and check them by eye against D11.)
2. Write header, constants, signatures only (bodies `throw new Error('not implemented')`). Header: what the module is, called from, why it exists, deliberately NOT done. Each constant gets the real reason, or `chosen by judgment`: never an invented reason. Each function gets a TSDoc comment: trust, return, copies or modifies, bad input. Done when it imports and the header answers who calls it, why, and what it does not do.
3. Write tests first, covering every decision id. One behaviour per test. For every limit: shrink by assigning to `memoryLimits` / `modelLimits` (restore it after), equal is valid, one more is an error (or skipped / cut, as D2 says), pin the default. Compare results with `toEqual`. Must-NOT tests for every non-goal and every D6 item (a transcript path outside `claude_home/projects`, a symlink that points outside, assistant text never becomes a fact, no model call for an empty input, the transcript is unchanged after the job). Public names, `mkdtemp` dirs, scratch schemas `ctc_t42_<random>`, fake `embed` / `chat` and `node:http` servers on random loopback ports only. The gate tests `memory.idempotent` and `memory.bands` (D16) are among them. Done when the tests collect and fail.
4. Smallest code that passes. Reuse the repo's helpers (`repos.memory`, `repos.sessions`, `memoryHash`, `JobDropped`, the `Handler` type). Add nothing the decisions do not list. Silence rule D8. Done when tests, checks, lint and scope pass.
5. Run the self-check, fix every FAIL. Done at `SELFCHECK: DONE`.
6. Report in at most 150 words: commands and results, every `judgment:` call, doubts.
