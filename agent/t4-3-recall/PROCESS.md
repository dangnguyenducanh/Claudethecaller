# Process for T4.3 `packages/core/src/memory` + `packages/shared/src/schemas/memory` + `apps/web/src/memory` + `apps/worker/src/memory` + the D17 repository edits + `.claude/metric/eval/memory` (TypeScript)

Every step ends with a check; the next step does not start before it passes. Language and file names adapted from the standard process: Python → TypeScript strict on Node 22, `pytest` → Vitest, `tests/test_*.py` → `*.test.ts` / `*.int.test.ts` next to the module, `NotImplementedError` → `throw new Error('not implemented')`, docstring → TSDoc comment, `monkeypatch` → assign to the exported `recallLimits` / `memoryApiLimits` object (or to `deps.config`) and restore it in `afterEach`. Module paths: as SPEC.md "How to work" step 3.

1. Read the callers and rules. Grep every call site. Done when you can say, per call site, what goes in, what is done with the result, and what the module must never do. Also run the real upstream producer on a sample and keep the output as a fixture.
   (Here: the bootstrap, the MCP server and the worker main do not exist yet; the "call sites" are the APIs this task must fit, named in DECISIONS.md D9 and D12-D17: `Route`, `McpTool`, `parse`, `toApiError`, `errorBody`, `statusOf` in `apps/web/src/library/http.ts` and how `apps/web/src/library/routes.ts` and `tools.ts` use them; `repos.memory` (`recallLegs`, `lastSummaries`, `list`, `get`, `getMany`, `patch`, `rewrite`, `softDelete`, `timeline`, `touch`, `getSummary`), `repos.projects` (`byRoot`, `list`), `repos.history` in `packages/shared/src/repositories/`; `keys`, `ttl`, `Cache.epoch` in `packages/shared/src/cache/`; the `memory.import`, `memory.distill`, `llm.extract` payloads in `packages/shared/src/queues/payloads.ts`; `memory.*` and `claude_home` in `packages/shared/src/env/schema.ts`; `sanitize`, `applyBands`, `BandPorts`, `memoryLimits` and the private `portsFor` in `packages/core/src/memory/` and `apps/worker/src/memory/index.ts` (T4.2). The real upstream producers are Claude Code (its SessionStart hook body, its memory files under `~/.claude/projects/*/memory/`, its transcripts) and you must not read `~/.claude`: write the fixtures by hand as `apps/web/src/memory/fixtures/hook-start.json` (`{session_id, transcript_path, cwd, hook_event_name: 'SessionStart', source: 'startup'}`) and `apps/worker/src/memory/fixtures/claude-home/projects/-x-proj/memory/` (a `feedback` file, a `user` file, a `project` file, a `MEMORY.md` index, a file without frontmatter, a file with CRLF and a BOM). Copy `agent/t4-3-recall/eval/` to `.claude/metric/eval/memory/` now (`cp agent/t4-3-recall/eval/* .claude/metric/eval/memory/`) and do not edit the copy.)
2. Write header, constants, signatures only (bodies `throw new Error('not implemented')`). Header: what the module is, called from, why it exists, deliberately NOT done. Each constant gets the real reason, or `chosen by judgment`: never an invented reason. Each function gets a TSDoc comment: trust, return, copies or modifies, bad input. Done when it imports and the header answers who calls it, why, and what it does not do.
3. Write tests first, covering every decision id. One behaviour per test. For every limit: shrink by assigning to `recallLimits` / `memoryApiLimits` / `deps.config.memory` (restore it after), equal is valid, one more is an error (or cut, skipped, dropped, as D2-D4 say), pin the default. Compare results with `toEqual`. Must-NOT tests for every non-goal and every D6 item (another project's memory never in the block, the block never over `context_chars`, the hook answers `204` within the budget when the store or the embedder hangs, no DB write on the hook path, memory files and transcripts unchanged, a symlink out of `claude_home/projects` is skipped, re-import adds no reinforcement date, distill never submits a path twice). Public names, `mkdtemp` dirs, scratch schemas `ctc_t43_<random>`, fake `embed` / `chat` / `submit` / `cache` only. The gate tests `memory.context` and `memory.recall` (D18) are among them; the T4.2 tests of `apps/worker/src/memory` must stay green after `bandPorts` replaces `portsFor`. Done when the tests collect and fail.
4. Smallest code that passes. Reuse the repo's helpers (`repos.*`, `keys`, `ttl`, `sanitize`, `applyBands`, `memoryHash`, the http.ts plumbing, the `Handler` type). Add nothing the decisions do not list. Silence rule D8. Done when tests, checks, lint and scope pass.
5. Run the self-check, fix every FAIL. Done at `SELFCHECK: DONE`.
6. Report in at most 150 words: commands and results (including the `memory.recall rrf@5=… vec@5=…` line), every `judgment:` call, doubts.
