# Process for T2.3 context parsers, doc extract, capability nodes (TypeScript)

Every step ends with a check; the next step does not start before it passes. Language and file names adapted from the standard process: Python → TypeScript strict on Node 22 (type stripping, `.ts` import suffixes, `erasableSyntaxOnly`), `pytest` → Vitest, `tests/test_*.py` → `*.test.ts` next to the code, `NotImplementedError` → `throw new Error('not implemented')`, docstring → TSDoc comment, `monkeypatch` → assign to the exported `contextLimits` / `contextWorkerLimits` objects (or the `config` object you pass) and restore them in `afterEach`. Modules: `packages/core/src/context/` (pure rules), `apps/worker/src/context/` (pass, capability link, extract job, composition), `packages/shared/src/repositories/graph.ts` (D17 only), `apps/worker/src/graph/rebuild.ts` (D11 only).

1. Read the callers and rules. Grep every call site. Done when you can say, per call site, what goes in, what is done with the result, and what the module must never do. Also run the real upstream producer on a sample and keep the output as a fixture.
   (Here: the call sites are the ones DECISIONS D0 names: `apps/worker/src/graph/{handler,rebuild,walk,limits}.ts` (T2.2: `Handler`, `readText`, `embedText`, `RebuildCache`, how `files`/`force` arrive), `apps/worker/src/library/{handlers,scan}.ts` (`library.changed`, `SubmitInput`), `packages/core/src/library/index.ts` (`NAME_RE`, `mainPathOf`, `bodyOf`), `packages/core/src/graph/{ids,resolve,types}.ts` (`cleanLabel`, `fileStem`, `SCORES`, node `type`/`label`/`meta.lines` of file and symbol nodes), `packages/shared/src/repositories/{graph,library,projects}.ts`, `packages/shared/src/queues/{payloads,defs}.ts`, `packages/core/src/sanitize/index.ts`. The real upstream producers are the repository's own documents and T2.1's `extractFile`: read the real `specs/007-ctc/spec.md` §8/§9, `specs/006-merged-core/spec.md`, `specs/002-context-coding-graph/{spec,tasks}.md`, `.scratch/context-coding-graph/issues/03-*.md` and `CLAUDE.md` and keep the D21 excerpts as fixtures; run `extractFile` on a small ts file to see the file/symbol node `label`s that `resolveRefs` must match.)
2. Write header, constants, signatures only (bodies `throw new Error('not implemented')`). Header: what the module is, called from, why it exists, deliberately NOT done. Each constant gets the real reason, or `chosen by judgment`: never an invented reason. Each function gets a TSDoc comment: trust, return, copies or modifies, bad input. Done when it imports and the header answers who calls it, why, and what it does not do.
3. Write tests first, covering every decision id. One behaviour per test. For every limit: shrink by assigning to the limits object or config (restore it after), equal is valid, one more is an error or a drop, pin the default. Compare errors with `toBe`/`toEqual` on `code` and `message`. Must-NOT tests for every non-goal. Public names, temp project directories under `os.tmpdir()`, `ctc_t23_` scratch schemas and a fake `runClaude` / fake shell script only. Done when the tests collect and fail.
   (Here: the gate file `parser.fixtures.test.ts` of DECISIONS D21 is among them; hand-write each expected JSON from DECISIONS, never from the output of your own code.)
4. Smallest code that passes. Reuse the repo's helpers (`cleanLabel`, `fileStem`, `makeId`, `SCORES`, `sanitize`, `NAME_RE`, `mainPathOf`, `bodyOf`, `readText`, `embedText`, `walkProject`, `checkPaths`, `safeRel`, `JobDropped`, `scratchRepos`). Add nothing the decisions do not list. Silence rule D8. Done when tests, checks, lint and scope pass.
5. Run the self-check, fix every FAIL. Done at `SELFCHECK: DONE`.
6. Report in at most 150 words: commands and results, every `judgment:` call, doubts.
