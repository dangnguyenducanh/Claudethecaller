# Process for T2.2 resolve, incremental rebuild, shrink guard, `graph` queue (TypeScript)

Every step ends with a check; the next step does not start before it passes. Language and file names adapted from the standard process: Python → TypeScript strict on Node 22 (type stripping, `.ts` import suffixes, `erasableSyntaxOnly`), `pytest` → Vitest, `tests/test_*.py` → `*.test.ts` next to the code, `NotImplementedError` → `throw new Error('not implemented')`, docstring → TSDoc comment, `monkeypatch` → assign to the exported `graphLimits` / `resolveLimits` objects (or the `config` object you pass) and restore them in `afterEach`. Modules: `packages/core/src/graph/` (resolver), `apps/worker/src/graph/` (walk, rebuild, handler), `packages/shared/src/repositories/graph.ts` (D22 only).

1. Read the callers and rules. Grep every call site. Done when you can say, per call site, what goes in, what is done with the result, and what the module must never do. Also run the real upstream producer on a sample and keep the output as a fixture.
   (Here: the call sites are the ones DECISIONS D0 names: `apps/worker/src/jobs/index.ts` + `consumers.ts` (`Handler`, how a throw becomes `jobs.error`), `apps/web/src/spool/index.ts` (the `graph.rebuild` payload it submits), `packages/shared/src/queues/payloads.ts`, `packages/shared/src/repositories/graph.ts` (`replaceSource`, `loadGraph`, `listSources`, `setEmbedding`), `packages/shared/src/cache/index.ts` (`epoch.rotate`, `publishInval`), `packages/shared/src/env/schema.ts` (`graph.*`), `apps/worker/src/library/handlers.ts` (the sibling handler to copy the deps shape from). The real upstream producer is T2.1's `extractFile`: run it with `loadGrammars()` on a few small ts/py/sh/md sources that import and call each other and keep the `ExtractResult`s as `apps/worker/src/graph/__fixtures__/extract-sample.json`.)
2. Write header, constants, signatures only (bodies `throw new Error('not implemented')`). Header: what the module is, called from, why it exists, deliberately NOT done. Each constant gets the real reason, or `chosen by judgment`: never an invented reason. Each function gets a TSDoc comment: trust, return, copies or modifies, bad input. Done when it imports and the header answers who calls it, why, and what it does not do.
   (Here: also run `pnpm --filter @ctc/worker add --save-exact ignore@7.0.14`.)
3. Write tests first, covering every decision id. One behaviour per test. For every limit: shrink by assigning to the limits object or config (restore it after), equal is valid, one more is an error or a skip, pin the default. Compare errors with `toBe`/`toEqual` on `code` and `message`. Must-NOT tests for every non-goal. Public names, temp project directories and `ctc_t22_` scratch schemas only. Done when the tests collect and fail.
   (Here: the two gate files of DECISIONS D23 are among them.)
4. Smallest code that passes. Reuse the repo's helpers (`extractFile`, `makeId`, `fileStem`, `langOf`, `EXTRACTOR_VERSION`, `repos.*`, `JobDropped`, `scratchRepos`). Add nothing the decisions do not list. Silence rule D8. Done when tests, checks, lint and scope pass.
5. Run the self-check, fix every FAIL. Done at `SELFCHECK: DONE`.
6. Report in at most 150 words: commands and results, every `judgment:` call, doubts.
