# Process for T3.3: SKILLRET dense + rerank skill channel (TypeScript)

Every step ends with a check; the next step does not start before it passes. Language and file names adapted from the standard process: Python → TypeScript strict on Node 22, `pytest` → Vitest, `tests/test_*.py` → `*.test.ts` next to the code, `NotImplementedError` → `throw new Error('not implemented')`, docstring → TSDoc comment, `monkeypatch` → pass fakes through `deps` (`repos`, `tei`, `cache`, `fetch`, `now`) and change a field of `skillLimits` / `teiLimits` in a test and restore it in `finally`. Modules: `packages/core/src/skills/`, `packages/shared/src/tei/`, `apps/web/src/skills/`, plus the small additions to `packages/shared/src/repositories/{library,tenancy.cases}.ts` and `apps/web/src/library/{served,index}.ts` that DECISIONS.md D9 and D21 name.

1. Read the callers and rules. Grep every call site. Done when you can say, per call site, what goes in, what is done with the result, and what the module must never do. Also run the real upstream producer on a sample and keep the output as a fixture.
   (Here: the call sites are `libraryHandlers` / `Embed` and the `library.changed` handler in `apps/worker/src/library/handlers.ts` (what is embedded, with which text and model); `repos.library.loadVectors`, `upsertVector`, `listOverrides` and the tenancy cases in `packages/shared/src/repositories/`; `overrideRows` in `apps/web/src/library/served.ts`; `keys.emb`, `ttl.emb`, `getVec`/`setVec`, `subscribeInval` and the `library.changed` event in `packages/shared/src/cache/`; the `k`, `depth`, `rerank_top`, `rrf_k`, `embed.*`, `ranking.*`, `timeout_s`, `batch_timeout_s` keys in `packages/shared/src/env/schema.ts` and `config/*.yaml`; `skillretText`, `sha256Hex`, `cosine` in `packages/core/src/library/`. The real upstream producers are the TEI servers: send one `/embed` request with two inputs to `127.0.0.1:18300` and one `/rerank` request with two texts to `127.0.0.1:18301` (curl or a throwaway script), and keep both replies (vectors cut to their first 8 numbers plus the length) as `apps/web/src/skills/fixtures/tei-embed.json` and `tei-rerank.json`; also read the first 2 skills and 2 queries of `.ctc-dev/eval/skillret-test.json` to see the gate data.)
2. Write header, constants, signatures only (bodies `throw new Error('not implemented')`). Header: what the module is, called from, why it exists, deliberately NOT done. Each constant gets the real reason, or `chosen by judgment`: never an invented reason. Each function gets a TSDoc comment: trust, return, copies or modifies, bad input. Done when it imports and the header answers who calls it, why, and what it does not do.
3. Write tests first, covering every decision id. One behaviour per test. For every limit: equal is valid, one more is an error (or is cut / clamped / batched, as DECISIONS.md says), pin the default. Compare results and errors with `toEqual`. Must-NOT tests for every non-goal (no reranker request at `rerank_weight 0`, no keyword work at `keyword_rrf_weight 0`, no repos call other than the two D6b names, no write, no throw with TEI or Postgres down, a blocked capability never returned). Public names, fakes, temp dirs and scratch schema names only. Done when the tests collect and fail.
4. Smallest code that passes. Reuse the repo's helpers (`repos.library.*`, `overrideRows`, `keys.emb`, `ttl.emb`, `skillretText`, `sha256Hex`, `loadConfig`, `migrate`). Add nothing the decisions do not list. Silence rule D8. Done when tests, checks, lint and scope pass.
5. Run the self-check, fix every FAIL. Done at `SELFCHECK: DONE`.
6. Report in at most 150 words: commands and results, every `judgment:` call, doubts.
